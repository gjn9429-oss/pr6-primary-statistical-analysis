## Запуск

З основної папки проєкту запустити всі блоки:

```powershell
python src/main.py
```

Або запустити потрібний блок окремо:

```powershell
python src/block1.py
python src/block2.py
python src/block3.py
python src/block4.py
```

## Блоки роботи

- `src/block1.py` – ранжування 20 заданих затримок, частоти, емпірична функція розподілу та числові характеристики.
- `src/block2.py` – групування 200 затримок мікросервісу A, гістограма, полігон частот і похибки групування.
- `src/block3.py` – додавання 10 аномальних значень, фільтрація за правилом IQR та порівняння вибірок на Boxplot.
- `src/block4.py` – аналіз 300 модельних значень завантаження CPU, гістограма та оцінка однорідності.
- `src/main.py` – послідовний запуск чотирьох блоків.

Результати виводяться в термінал. Графіки зберігаються в `graphics/`
без відкриття окремих вікон. У `report/` міститься [звіт у PDF](report/PR11_12_Report_Rymarenko.pdf).

## Дані експерименту

У блоці 1 використано список із методички. Емпірична функція рахує
значення, строго менші за x: `F*(x) = кількість(X < x) / n`.

У блоці 2 вибірка містить 190 значень N(150, 20²) мс і 10 сплесків
U(200, 300) мс. Це рівно 5% сплесків із загальних 200 вимірів;
після генерації значення перемішуються. Зерно генератора – 42.
У блоці 3 використано ту саму початкову вибірку; до неї додано
10 значень, більших за середнє + 5S. Квартилі обчислюються лінійною
інтерполяцією, фільтр IQR застосовується один раз.

Для блока 4 прийнято навчальну модель U(20, 90) % із зерном 43,
оскільки методичка не надає логів CPU або закону їх генерації.
Це модельні значення; висновок стосується саме цієї вибірки.

Повторний запуск відтворює дані й оновлює графіки. Запуск перевірено
з Python 3.14.7, NumPy 2.5.2 та Matplotlib 3.11.2.
